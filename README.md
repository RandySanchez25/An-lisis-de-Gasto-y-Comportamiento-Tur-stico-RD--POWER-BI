# An-lisis-de-Gasto-y-Comportamiento-Tur-stico-RD--POWER-BI
Dashboard interactivo en Power BI sobre el análisis de gasto y comportamiento turístico en República Dominicana (2022–2025), evaluando el gasto en USD, estadía promedio y evolución anual de visitantes extranjeros por trimestre y categoría.
